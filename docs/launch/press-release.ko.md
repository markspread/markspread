# 보도자료 — 마크스프레드 1.0

> 한국 매체용 보도자료. 영문판은 `press-release.en.md`.
> 엠바고: 1.0.0 정식 출시 시각 (KST 화요일 16:00).
> 연락처: <press@markspread.app>

## 제목

**마크스프레드 1.0 출시 — CSS-충실 미리보기와 온디바이스 AI 를
갖춘 오픈소스 마크다운 에디터**

## 부제

맥, 윈도우, 리눅스용 데스크톱 에디터로, 게시 사이트의 실제 CSS 로
미리보기를 렌더링하는 "스프레드 패널" 과 사용자 본인의 API 키로만
동작하는 AI 기능을 결합. 모든 빌드는 공개 커밋 해시로부터 재현
가능하며 코드 서명되어 배포된다.

## 본문

마크스프레드 메인테이너는 오늘 마크스프레드 1.0 을 정식 출시한다.
마크스프레드는 데스크톱용 오픈소스 마크다운 에디터로, Rust 와
Tauri 2 로 작성된 단일 코드베이스에서 macOS, Windows, Linux 네이티
브 바이너리가 빌드된다. 소스는 <https://github.com/markspread/markspread>
에 공개되어 있다.

핵심 차별점은 *스프레드 패널* — 사용자가 발행하려는 사이트의 CSS
를 그대로 샌드박스 iframe 에 로드해 미리보기를 렌더링한다. 팀의
주장은 단순하다: 대부분의 마크다운 에디터는 일반 스타일시트로 미
리보기를 그리기 때문에 저자가 발행 후에야 깨진 부분을 발견하게 된
다. 마크스프레드는 *실제 CSS* 를 재사용하므로, 작성 중 보이는 화
면이 곧 게시 결과이다.

두 번째 축은 AI 프라이버시다. 경쟁 제품 다수가 AI 요청을 자사
서버를 경유시키는 것과 달리, 마크스프레드는 사용자가 선택한 프
로바이더 (OpenAI, Anthropic, 또는 Ollama / llama.cpp 등 로컬 모
델) 로 프롬프트와 응답을 직접 전송한다. API 키는 OS 키체인에 저
장되며 프로젝트는 어떠한 AI 릴레이도 운영하지 않는다.

마크스프레드는 MIT 라이선스로 배포된다. 릴리스는 공개 커밋 해시
로부터 재현 가능하며, macOS 는 Apple Notarisation, Windows 는 EV
코드사이닝, 업데이트 채널은 Ed25519 로 서명된다. 플러그인 마켓
플레이스는 1차 플러그인 4종과 함께 오픈 등록 절차를 제공하며, 모
든 플러그인은 명시적인 파일시스템·네트워크 범위와 함께 별도 렌
더러에서 샌드박스 동작한다.

마크스프레드 팀은 한국에 거점을 둔 소규모 팀으로, 외부 투자 없이
자체 자금으로 운영된다. 데스크톱 앱과 함께 CLI (`markspread-cli`),
플러그인 SDK (`@markspread/sdk`), 마켓플레이스가 동시 출시된다.

## 핵심 사실

- **콜드 스타트:** 2024 MacBook Air 기준 약 220ms
- **유휴 메모리:** 약 85 MB
- **설치 파일 크기:** macOS 18 MB / Windows 22 MB / Linux AppImage 24 MB
- **텔레메트리:** 기본 OFF, 옵트인 시 주간 회전 클라이언트 ID 사용
- **라이선스:** MIT
- **소스:** <https://github.com/markspread/markspread>

## 인용

메인테이너 인용:

> 대부분의 마크다운 에디터는 15년 전에 편집 문제를 풀었습니다. 그
> 후로 계속 놓치고 있는 건 미리보기와 실제 발행 결과의 차이입니다.
> 우리는 새 포맷을 만들거나 노트 앱을 바꾸라고 요구하지 않고 그
> 차이를 좁히고 싶었습니다.

AI 설계 관련 인용:

> AI 기능을 유용하게 만들면서도 사용자와의 약속을 지키고 싶었습
> 니다 — 키도, 머신도, 프롬프트도 사용자의 것입니다. 사용자가 프
> 로바이더를 신뢰한다면, 앱이 필요로 하는 신뢰 관계는 그것 하나
> 뿐입니다.

## 프로젝트 소개

마크스프레드는 오픈소스 마크다운 에디터 및 도구 프로젝트다. 데
스크톱 앱이 주력 제품이며, 동반 출시 제품으로 스크립트·CI 용
`markspread-cli`, 플러그인 작성용 `@markspread/sdk`, 그리고 플러
그인 마켓플레이스가 있다. 프로젝트는 소규모 팀이 운영하며,
<https://github.com/markspread> 에 공개 개발된다.
