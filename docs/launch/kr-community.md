# 한국 커뮤니티 런칭 패킷

마크스프레드는 한국 팀이 만들었기 때문에 한국 개발자 커뮤니티는
일반 영어권 채널보다 한 박자 빠르게, 더 솔직한 톤으로 접근한다.
영문 PH/HN 글의 단순 번역이 아닌, 각 커뮤니티 특유의 분위기에 맞춰
별도로 글을 쓴다.

## 타이밍 (KST)

| 시각        | 채널           |
|-------------|----------------|
| 화요일 22:00 | 긱뉴스 (news.hada.io) — 영문 PH 직후 |
| 화요일 22:30 | 클리앙 모공 (clien.net/service/board/park) |
| 수요일 09:00 | OKKY 자유게시판 |
| 수요일 12:00 | 디스콰이엇 (disquiet.io) — 메이커 글 |

월요일 새벽이나 주말은 피한다. 이는 영문 채널과 같은 이유 — 이용자
유입이 낮기 때문이다.

## 채널별 노트

### 긱뉴스 (news.hada.io)

긱뉴스는 한국에서 가장 영향력 있는 개발자 큐레이션 사이트 중 하나.
규칙:

- **자기 작품 글은 본인 작성자임을 본문에 명시**한다. 익명으로
  올리면 모더레이션이 강제로 표시한다.
- **요약 본문은 사실 위주**로 쓴다. 광고성 어조는 곧바로 탈락.
- **링크는 한 개**만 — 메인은 markspread.dev. 깃헙은 본문에서
  텍스트로 언급.

#### 제안 본문

```
[직접 만든 거 공개합니다] 마크스프레드 1.0 — CSS-충실 스프레드
패널을 가진 마크다운 에디터

마크스프레드는 데스크톱 마크다운 에디터입니다. 핵심 차별점은
오른쪽 미리보기 패널이 *실제 게시될 사이트의 CSS* 를 그대로
사용한다는 점 — Lorem 스타일이 아니라 진짜 발행 결과를 봅니다.

- AI 기능: 사용자의 OpenAI/Anthropic 키로 직접 호출. 키는 OS
  키체인에만 저장. 우리 서버는 경유하지 않음. Ollama / llama.cpp
  로컬 모델 지원.
- 성능: 220ms 콜드 스타트, 85MB 유휴 메모리, 18MB 인스톨러 (M1
  맥북에어 기준). Tauri 2 + Rust + CodeMirror 6.
- 라이선스: MIT. 빌드 재현 가능, Yubikey 로 서명.
- 플랫폼: 맥 / 윈도우 / 리눅스. 무료, 계정 가입 없음.

긱뉴스 분들 피드백 듣고 싶습니다. 특히 한글/CJK 처리 (조합 입력
중 IME 깜빡임, 세로쓰기, 종성 처리) 쪽으로 깐깐하게 봐주시면
감사하겠습니다.

소스: github.com/markspread/markspread
다운로드: markspread.dev
```

### 클리앙 모공

모공은 정보성 글이 통하지만 마케팅 톤은 거부 반응이 강하다. 본문
은 짧게, 댓글에서 풀어 쓰는 게 클리앙 스타일.

#### 제안 본문

```
[정보] 마크다운 에디터 만들었어요 — 미리보기가 진짜 발행 CSS

오랫동안 마크다운 에디터 쓰면서 미리보기랑 실제 게시 결과가 달라서
짜증났던 분들 계실 것 같습니다. 그 부분만 해결한 에디터를 1년 정도
만들어 봤어요.

- 미리보기 = 사이트에 발행되는 그대로의 CSS
- AI 기능은 본인 API 키로만 동작 (서버 경유 X)
- 맥/윈/리눅스 무료, MIT 오픈소스

markspread.dev 에서 받을 수 있고, 사용해 보시고 이상하다 싶은 부분
있으면 댓글 남겨주세요. 만든 사람이 직접 답합니다.
```

### OKKY 자유게시판

OKKY 는 실무 개발자 비율이 높고 "왜 또 마크다운 에디터?" 식의
질문이 많이 달리는 곳이다. 그 질문에 미리 답하는 톤으로 쓴다.

#### 제안 본문 — 핵심만

OKKY 는 클리앙보다 본문 길이를 허용하므로 긱뉴스 본문에 다음을
추가한다:

- "왜 옵시디언/타이포라/베어가 있는데 또 만들었나" 한 단락
- 한국어 입력 (IME 조합 중 잘림 방지) 케이스 강조
- 관련 채용 / 컨트리뷰터 모집 한 줄 (OKKY 는 채용 글이 많아
  자연스럽다)

### 디스콰이엇 메이커 게시판

디스콰이엇은 메이커 스토리에 더 무게를 둔다. 기능 나열보다 "왜
만들었는지" 가 통한다.

#### 톤

- 1인칭 시점 — 만든 사람 입장.
- 어려웠던 결정 1개 (예: Tauri 채택 vs Electron) 솔직하게 공유.
- 디스콰이엇 댓글은 대부분 응원이지만 가끔 날카로운 질문이 온다.
  사실 위주로 답할 것.

### 한국어 X (Twitter) 미러

영문 X 스레드를 그대로 번역하지 않고, 한국어 X 사용자에게 맞춰
다음 변경을 한다:

- 첫 트윗에 "🇰🇷 한국에서 만들었습니다" 한 줄 추가.
- 데모 비디오 자막은 한국어 트랙을 기본으로 켠다 (S-LCH-003 의
  ko.vtt).
- 댓글로 한국어 사용자 친화 기능 (IME, 한글 단어 단위 검색,
  세로쓰기 안 됨 등 한계 솔직하게)을 별도 트윗.

## 답변 모드

- 댓글에는 **존댓말**로 응답. 반말은 친한 사람에게도 쓰지 않는다.
- 비판적 질문에는 동의할 부분은 동의하고 사실로 반박할 부분만
  반박. "검토하겠습니다" 같은 회피성 답은 한국 커뮤니티에서도
  마이너스.
- 이미 영문 HN / X 에서 답한 질문이 또 들어와도 새로 작성. 이전
  답을 그대로 복사하면 즉시 들통난다.

## 하지 않는 일

- **여러 커뮤니티에 동시 도배 금지.** 같은 본문, 같은 시간에 여러
  곳에 올리는 건 알 수 있다.
- **자추 / 추천 부탁 금지.** 한국 커뮤니티는 이런 데 특히 민감하다.
- **광고 어휘 회피.** "혁신적인", "차세대", "최고의" — 모두 안
  쓴다.

## 회고

런칭 회고 (S-LCH-011) 에 채널별 유입, 댓글 핵심 피드백 3개,
모더레이션 이슈가 있었으면 그 내역을 기록한다. 다음 마일스톤
런칭 시 이 문서를 업데이트한다.
